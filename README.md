# SNOWPEAK — лабораторная работа №3

Интернет-магазин зимнего спортивного инвентаря (вариант 6).

## Технологии

- React + Vite — клиентская часть
- Node.js + Express — REST API
- SQLite (`better-sqlite3`) — хранение товаров, заказов, броней, пользователей и сообщений

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`. API доступно на `http://localhost:3001`.

В файле `snowpeak.db`, который автоматически создаётся после запуска сервера, сохраняются новые заказы и обращения из формы.
